Project case study

TutorFind

An Android tutoring platform developed as part of the Bachelor of Information Technology at Nelson Mandela University. It is designed to connect students with tutors through a mobile application.

Android Application Development / Academic Final-Year ProjectJava · Android Studio · ASP.NET · .NET Framework · MySQL · Git / GitHub

Project overview

The student-oriented platform allows users to explore tutoring opportunities, while individuals interested in tutoring can apply to become tutors. The project required consideration of mobile functionality, backend communication and database integration.

Technical implementation & architecture

Java and Android Studio were used for Android development. ASP.NET and the .NET Framework formed part of the backend stack, with MySQL used for database-related functionality and data management. The project connected application functionality with backend and database components.

Concepts demonstrated

  • Java
  • Android development
  • object-oriented programming
  • backend concepts
  • database connectivity
  • MySQL integration
  • application/database communication
  • debugging
  • multi-user application design.
A development challenge involved database connectivity. Troubleshooting included investigating driver dependencies and database connection-string configuration. This provided practical exposure to debugging the relationship between application code, database drivers and configuration.
