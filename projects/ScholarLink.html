Project case study

ScholarLink

A full-stack academic collaboration and student support platform designed to bring tutoring, study groups, academic resources and student communication into one centralised environment.

Education Technology / Full-Stack Development C# · ASP.NET Core · Entity Framework Core · MySQL · HTML · CSS · JavaScript · REST APIs

Project overview

ScholarLink originated from an observation during my university studies: students often have to navigate several disconnected platforms and communication channels to access academic support, find tutors, organise study groups and obtain learning resources.

The project explores how these activities can be brought together through a centralised academic support platform. It provides a structured environment where students can discover tutors, arrange tutoring sessions, participate in study groups, communicate with other users and access shared learning resources.

ScholarLink also incorporates administrative functionality to support the management of users, academic institutions, faculties, modules and platform activities. The system is designed around different user roles, ensuring that access to administrative and academic functions is controlled according to permissions.

Technical implementation & architecture

ScholarLink follows a client-server architecture, separating the frontend interface, backend application logic and relational database.

The backend is developed using C# and ASP.NET Core Web API. It exposes RESTful endpoints responsible for authentication, user administration, institutional management, tutoring workflows, study groups, messaging, learning resources and notifications.

Entity Framework Core is used as the object-relational mapping framework, connecting the application models to a MySQL 8.0 database. The database structure uses relational entities, primary keys, foreign keys and indexes to organise academic and platform information.

ASP.NET Core Identity handles user account management and role-based access control, while JWT authentication supports authenticated API communication. The frontend is developed using HTML, CSS and JavaScript, providing the user-facing pages and communicating with the backend through HTTP requests.

Core system functionality

  • User registration, login and authenticated access
  • Role-based access for platform administrators, institution administrators, coordinators, tutors and students
  • Administrative user creation and account management
  • Institution, faculty and academic module management
  • Tutor applications, discovery and approval workflows
  • Tutor availability and tutoring session management
  • Study group creation and membership management
  • Conversation and messaging functionality
  • Learning resource management and file downloads
  • Notifications and academic announcements
  • Tutor reviews and feedback

Database design & data management

The application uses a relational database designed around the relationships between users, institutions and academic activities.

Its data model includes entities for user accounts, institutions, faculties, academic modules, student and tutor profiles, tutoring sessions, availability, study groups, group memberships, conversations, messages, learning resources, reviews, notifications and announcements.

Entity Framework Core manages database interactions and relationships, while MySQL provides persistent data storage. The application is configured to initialise its database schema when connecting to an empty database.

Project objectives

The primary objective of ScholarLink is to explore how software engineering can address practical challenges within higher education. The project brings together several academic support workflows in a single application while demonstrating the design and development of a structured, database-driven software system.

It also serves as a practical demonstration of full-stack development, backend engineering, database architecture, API integration, authentication and application-level access control.

ScholarLink is an independently developed software project. Its functionality and architecture are intended to demonstrate practical software development and academic collaboration workflows. It is not presented as an officially integrated university platform.
