ExpenseTracker

A personal finance management application designed to help organise and monitor financial activities.

Financial Software / Java Application DevelopmentJava · MySQL · SQL

Project overview

The project combines Java application logic with a MySQL relational database to explore how software can manage and store structured financial information.

Technical implementation & architecture

Java implements application logic and processes information. MySQL stores and manages application data, while SQL supports queries and database operations.

  • object-oriented programming
  • classes and objects
  • methods
  • relational database concepts
  • SQL queries
  • Java and MySQL integration
  • data persistence.
Highlights database-driven application development and object-oriented programming.
